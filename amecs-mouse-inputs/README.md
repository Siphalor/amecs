## About

This mod allows using additional mouse inputs for keybindings.
Currently, this only includes the mouse wheel.

## Usage

The following mouse input codes are added:
- `512`: Scroll up
- `513`: Scroll down
- `514`: Scroll left (Minecraft 1.20.2+)
- `515`: Scroll right (Minecraft 1.20.2+)
