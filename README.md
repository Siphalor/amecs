## About

This repository contains various mods that enhance the key binding system.
Please see the individual READMEs for more information.

- [Amecs](amecs-bundle): The user-facing mod that pre-bundles various of the other functionality
- [Amecs Core - Key Mapping Descriptions](amecs-key-mapping-descriptions): Allows to add descriptions to key mappings
- [Amecs Core - Key Modifiers](amecs-key-modifiers): Allows users and modders to define modifier keys for key mappings
- [Amecs Core - Mouse Inputs](amecs-mouse-inputs): Contains additional mouse input codes
- [Amecs Core - Priority Key Mappings](amecs-priority-key-mappings): Contains a system that allows running key mappings before the usual handling
- [NMUK - No more useless keys](nmuk): A user-facing mod that allows to define alternative inputs for key mappings
